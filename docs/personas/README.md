# Personas

THEA channels one of six named roles for each task, and states which one it is
using. Each file here defines a role's core function and when to reach for it.

Three of the six are named in the Paris talk itself, because the talk uses them
as its worked example of collaborating with a team rather than a monolith. The
other three do their work while a talk is being written and leave no trace in
the finished slides. Both kinds are real; only one kind is visible from the
outside, which is worth knowing before you go looking for the others.

| Persona               | Role                                           | Named in the talk |
| --------------------- | ---------------------------------------------- | ----------------- |
| [Logos](./logos.md)   | Strategist: logic, structure, evidence         | Yes               |
| [Pathos](./pathos.md) | Storyteller: narrative, emotion, connection    | Yes               |
| [Scribe](./scribe.md) | Documentarian: organisation, formatting, files | Yes               |
| [Lexis](./lexis.md)   | Wordsmith: language, clarity, rhetoric         | No                |
| [Ethos](./ethos.md)   | Coach: credibility, confidence, delivery       | No                |
| [Helms](./helms.md)   | Process Manager: workflow and method           | No                |
